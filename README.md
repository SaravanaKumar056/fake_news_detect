# Fake News Detector 📰🤖

This project detects fake news using Machine Learning (Logistic Regression and Decision Tree).

## Tech Stack
- Python
- scikit-learn
- pandas, matplotlib, seaborn
- NLP with NLTK
- TF-IDF vectorizer

## Dataset
[Fake and Real News Dataset (Kaggle)](https://www.kaggle.com/clmentbisaillon/fake-and-real-news-dataset)

## How it Works
- Text preprocessing (cleaning, tokenization)
- TF-IDF vectorization
- Classification using Logistic Regression and Decision Tree
- Visualization using WordCloud and Bar Charts

## Accuracy
- Logistic Regression: ~95% (Train), ~92% (Test)
- Decision Tree: ~100% (Train), ~87% (Test)

## Future Scope
- Use LSTM or BERT for better results
- Build a web UI with Streamlit or Flask
